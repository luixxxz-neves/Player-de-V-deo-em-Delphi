# Player-de-Video-em-Delphi
Projeto de player de vídeo feito do zero em Delphi 2007 usando o componente WMPlib.

Observações:
Esse projeto tem um ponto importante para funcionar em outros computadores.

Na pasta C:, crie uma pasta com o nome 'Filme' e dentro dela adicione um arquivo .mp4 contendo a mídia que deseja exibir, o nome do arquivo também deve ser 'Filme', ficando com o caminho de arquivo "C:\Filme\Filme.mp4".

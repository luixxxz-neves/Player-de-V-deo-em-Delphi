# Player-de-Video-em-Delphi
Projeto de player de vídeo feito do zero em Delphi 2007 usando o componente WMPlib.

Observações:
Esse projeto tem um ponto importante para funcionar em outros computadores.

1- Na pasta C:, crie uma pasta com o nome 'Filme' e dentro dela adicione um arquivo .mp4 contendo a mídia que deseja exibir, o nome do arquivo também deve ser 'Filme', ficando com o caminho de arquivo "C:\Filme\Filme.mp4".

2- Existe a possibilidade de declarar clientes com níveis dentro do código através de uma banco de dados. São 3 níveis de acesso : 1 com anúncios a cada 10 segundos de vídeo, 2 com anúncios a cada terço de vídeo e 3 sem anúncios. O banco de dados com essas tabelas não pode ser diponibilizado, então tem que fazer do zero com as tabelas relacionadas cliente e planos para usar essa funcionalidade.
